# Authfly widgets (authkit)

Sign-in, sign-up, magic link, password reset, account and consent widgets for eight runtimes, generated by
[ui8kit/codegen](https://github.com/ui8kit/codegen) from the specs in `specs/` with the same DOM everywhere.

| Runtime | Package / folder |
|---|---|
| React | `@authfly/react` (`packages/ui/react`) |
| Vue | `@authfly/vue` (`packages/ui/vue`) |
| Svelte | `@authfly/svelte` (`packages/ui/svelte`) |
| Solid | `@authfly/solid` (`packages/ui/solid`) |
| templ (Go) | `packages/ui/templ` |
| Twig, Latte (PHP) | `packages/ui/twig`, `packages/ui/latte` |
| Jinja2 (Python) | `packages/ui/jinja2` |

The widgets are plain HTML forms ([form contract](docs/contract.md)): point `action` at any backend. The Authfly
server ([authfly/cli](https://github.com/authfly/cli)) uses this set for its hosted pages.

## Develop

```sh
bun install
bun run gen:ui      # regenerate packages/ui from specs/ (pristine codegen checkout pinned in codegen.lock, no upstream edits)
bun run verify:ui   # + codegen verify: DOM parity of templ, solid, twig, jinja2, latte vs React, codex, typecheck, tests
npx ui8px@latest lint
bun run site        # docs + live previews -> site/dist
```
