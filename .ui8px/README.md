# ui8px policy

Generated by `npx ui8px init` (defaults: 8 px layout steps, 4 px steps inside controls). Additions to `allowed.json`
`utilities`, all used by the generated ui8kit templ primitives (breadcrumb, card, theme toggle) and not by Authfly code:
`underline`, `underline-offset-4`, `auto-rows-min`, `size-4`, `size-5`.

ui8px 0.2.5: `inset-ring*` is a ring utility (not `inset-*` spacing) and must be allowlisted; added the token rings used
by the Authfly skin and docs site: `inset-ring`, `inset-ring-{border,input,ring,primary,transparent,success,warning,destructive}`.
`scopes.json` adds `controls-templ` (control spacing) for the templ kit primitives and utils (`packages/ui/templ/ui/**`,
`packages/ui/templ/utils/**`, as in `ui8px init --preset go`) and the control recipes in `packages/ui/templ/authfly/skin.go`;
widgets/blocks and the site stay in layout scope. Spacing scales unchanged.
Non-spacing utilities used by the Authfly skin, widgets and docs site (no spacing values, no arbitrary values):
`list-none`, `transition-colors`, `outline-none`, `cursor-not-allowed`, `pointer-events-none`, `accent-primary`,
`border-b`, `border-t`, `uppercase`, `leading-7`, `size-12` (48 px).
Accepted violation (owner, 2026-10-24): ui8px 0.2.5 has no policy-level exceptions and a hard-coded modifier list
without `placeholder:`, so `placeholder:text-muted-foreground` in `InputSkin` (`skin.go`) is the one UI8PX002 that
`bun run lint:px` reports; the class stays as is.
